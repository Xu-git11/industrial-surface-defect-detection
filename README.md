# 工业零件表面缺陷检测系统

基于 OpenCV 的传统机器视觉缺陷检测流水线，含**两种检测方法的工程对比**、**参数调优过程**与**可复现的评估指标**。

> 定位：面向机器视觉应用工程师岗位的入门实战项目。不追求 SOTA，重点是把
> 「预处理五步 → 分割 → 形态学 → Blob 分析 → 指标评估」这条工业现场的主流流程跑通，
> 并且能说清每一步为什么这么做。

---

## 一、为什么做这个项目

工业产线的外观检测（划痕、破损、污渍）是机器视觉最典型的落地场景。
实际项目中工程师面对的往往不是"训一个大模型"，而是：

- 相机、镜头、光源怎么选，打光方案怎么定
- 工件能否稳定定位，定位误差有多大
- 用传统算子能不能解决（成本低、可解释、易过客户验收）
- 误检率和漏检率怎么权衡，产线节拍能不能满足

这个项目就是为了把上述问题工程化地走一遍。

## 二、检测方法

### 方法 A：局部自适应阈值（`--method adaptive`）

不依赖良品模板，直接在前景区域内用 `adaptiveThreshold` 找偏离局部背景的暗区/亮区。

- 优点：不需要建模板，单张图即可检测
- 缺点：物体自身的纹理、受光渐变都会被当成异常

### 方法 B：模板差分法（`--method diff`，**推荐**）

工业现场的主流做法：

1. 采集 N 张确认合格的良品图像，取像素级均值作为**标准件模板**
2. 待测图与模板逐像素求差：`|待测 − 模板| > 阈值 → 缺陷`
3. 阈值自适应：`阈值 = max(k_std × 良品自身标准差, 下限)`
   —— 以良品正常波动为基准，避免把噪声和纹理误判成缺陷
4. 形态学开运算去噪点、闭运算连接断裂缺陷
5. Blob 连通域分析，按面积过滤残留噪声

- 前提：相机与光源固定、工件由夹具定位（位置抖动要小）
- 优点：对真实缺陷敏感，误检率低
- 缺点：对上料定位误差敏感

## 三、评估结果

在合成数据集（`bottle` 类，80 张：20 训练良品 + 15 测试良品 + 3 类缺陷各 15 张）上：

| 方法 | IoU | Precision | Recall | 误检率 | 漏检率 |
|---|---|---|---|---|---|
| **模板差分法** | **0.757** | **0.931** | 0.793 | **0.0%** | **2.2%** |
| 局部自适应阈值 | 0.179 | 0.237 | 0.185 | 0.0% | 75.6% |

> - **误检率** = 良品被判成不良品（产线上会造成不必要的复检和停线）
> - **漏检率** = 不良品被判成良品（流出到客户端，最严重的质量事故）

结论：在"工件可稳定定位"的前提下，**模板差分法把漏检率从 75.6% 降到 2.2%**，
代价是需要建模板、对定位精度有要求。这正是现场方案选型要权衡的地方。

## 四、参数调优

差分阈值系数 `k_std` 的扫描结果（`min_area` 固定 40）：

| k_std | IoU | Precision | 误检率 | 漏检率 |
|---|---|---|---|---|
| 3.5 | 0.729 | 0.886 | 13.3% | 2.2% |
| 4.0 | 0.741 | 0.906 | 13.3% | 2.2% |
| **5.0** | **0.757** | **0.931** | **0.0%** | **2.2%** |
| 6.0 | 0.755 | 0.933 | 0.0% | 2.2% |

`k_std` 从 4.0 提到 5.0 时，误检率从 13.3% 归零，而 IoU 不降反升
（说明被滤掉的确实是噪声而非缺陷）；继续提到 6.0 收益消失，说明已到拐点。
最终取 **k_std = 5.0**。

## 五、快速开始

```bash
# 1. 建环境
python -m venv cv_env
cv_env\Scripts\activate          # Linux/Mac: source cv_env/bin/activate

# 2. 装依赖
pip install -r requirements.txt

# 3. 生成合成数据集（未下载真实 MVTec AD 时用这个）
python prepare_demo_data.py

# 4. 跑检测（两种方法一并对比）
python 01_traditional_opencv.py --data data/mvtec_ad_demo --category bottle --method both
```

产出：
- 终端指标表
- `outputs/01_traditional/metrics.json`
- `outputs/01_traditional/*.png`：每张图的「原图 | 差分图/分割图 | 预测 | GroundTruth」四联对比

| 数据集 | 状态 | 说明 |
|---|---|---|
| 合成数据集 | ✅ 已内置 | `prepare_demo_data.py` 生成，固定随机种子可复现 |
| MVTec AD（真实） | ⏳ 待接入 | 官方下载 https://www.mvtec.com/company/research/datasets/mvtec-ad |

合成数据的设计：

- 物体位置固定，仅保留 ±2px 上料抖动 —— 模拟相机与夹具定位，这也是差分法成立的前提
- 加入纹理与高斯噪声 —— 让检测不是白送分，误检率不会天然为 0
- 三类缺陷对比度递减（大破损 > 污渍 > 小划痕）—— 用于观察算法的能力边界

接入真实数据后：

```bash
python 01_traditional_opencv.py --data data/mvtec_anomaly_detection --category bottle --method diff
```

## 九、面试常见问题（自问自答）

**Q：为什么用传统方法而不是深度学习？**
> 工业现场很多场景（划痕、缺料、尺寸测量）用传统算子就能解决，成本低、
> 可解释、客户容易验收，也不需要大量缺陷样本。深度学习更适合缺陷形态复杂、
> 类别多、需要分类的场景。我的做法是先跑通传统流程建立基线，再对比深度学习。

**Q：误检率和漏检率怎么权衡？**
> 取决于缺陷流出的代价。汽车零部件这类安全件，漏检代价极高，宁可误检高一点；
> 而误检会拖慢节拍、增加复检成本。所以阈值不能拍脑袋定，要跟客户确认可接受的漏检率。

**Q：工件定位不准怎么办？**
> 这是模板差分法最大的风险。解决方案：一是在差分前用模板匹配或特征点做亚像素对齐；
> 二是从机械上保证夹具定位精度；三是改用对位置不敏感的方法（如频域分析、
> 或基于深度特征的 PatchCore）。

**Q：打光为什么重要？**
> 打光直接决定缺陷和背景的对比度。比如反光金属件要用同轴光消除高光，
> 尺寸测量用背光获取清晰轮廓，表面划痕用低角度光突出凹凸。
> 算法再好，打光没做好也检不出来——现场调试大部分时间花在打光上。
